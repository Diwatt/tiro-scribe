# Design Inspiration & App Examples

## Status Header Design

The new pipeline status header shows:
- **4 Stages**: Record → Transcribe → Anonymize → Complete
- **Visual Indicators**: Active stages are highlighted with colored icons
- **Queue Counts**: Shows number of items in each stage
- **Current Status**: Text indicator showing what's happening now
- **Connectors**: Visual flow between stages

## Design Principles Applied

1. **Visual Hierarchy**: Most important info (current stage) is prominent
2. **Color Coding**: Each stage has a distinct color (error=recording, primary=transcribe, secondary=anonymize, tertiary=complete)
3. **Progressive Disclosure**: Details (counts) shown only when relevant
4. **Real-time Updates**: Status reflects current state immediately
5. **Accessibility**: Clear labels and high contrast for all states
